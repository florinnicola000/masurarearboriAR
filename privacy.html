1. Identitatea operatorului

Aplicația TreeMeasureAR (MasurareArbori) este dezvoltată și publicată de Florin Nicola, contact: nicolaflorin00@icloud.com.

2. Date colectate și scopul colectării

Aplicația colectează și stochează exclusiv pe dispozitivul utilizatorului:

Categorie date Detalii Obligatoriu?
Măsurători forestiere Diametru (D1, D2, Dm), înălțime, volum, suprafața de bază, număr arbore, clasă calitate, specie, unitate amenajistică Da — funcționalitatea de bază
Locație GPS (precisă) Coordonate WGS84 (latitudine, longitudine) atașate fiecărei măsurători și punctelor de traseu GPS Opțional — utilizatorul acordă permisiunea
Locație aproximativă Derivată din aceeași permisiune ACCESS_FINE_LOCATION Opțional
Fotografii cioate Poze ale cioatelor, salvate local cu watermark (coordonate GPS + număr cioată) Opțional — funcție separată de inventariere cioate
Setări aplicație Înălțimea operatorului, factorul de corecție diametru, ultima unitate amenajistică folosită Da — preferințe locale

3. Mod de stocare

  • Toate datele sunt stocate în baza de date internă a aplicației (treemeasurear.db) pe dispozitivul utilizatorului.
  • Nu există server propriu. Nu există cont de utilizator. Nu există sincronizare în cloud.
  • Fotografiile sunt salvate în memoria internă a dispozitivului.
  • Setările sunt în SharedPreferences locale.

4. Transmitere și partajare cu terți

  • Nu există transmitere automată a datelor către niciun server sau terț.
  • Exportul fișierelor (CSV, PDF, GeoJSON) este inițiat exclusiv de utilizator și trimis prin aplicațiile de pe dispozitiv (email, WhatsApp etc.).
  • Harta din aplicație folosește tile-uri OpenStreetMap (descărcate via HTTP); niciun identificator al utilizatorului nu este trimis.
  • Nu există SDK-uri de publicitate, analiză (Analytics, Firebase, Crashlytics) sau third-party tracking.

5. Permisiuni cerute

  • CAMERA — necesară pentru realitatea augmentată și fotografierea cioatelor
  • ACCESS_FINE_LOCATION — opțional; solicitat numai pentru geotagging și traseu GPS
  • READ_EXTERNAL_STORAGE — solicitat numai pe Android < 13 pentru backup/restore

6. Retenție date

Datele sunt păstrate pe dispozitiv până când utilizatorul le șterge explicit (buton în aplicație) sau dezinstalează aplicația.

7. Drepturile utilizatorilor

  • Acces: toate datele sunt vizibile în aplicație (ecranul Istoric)
  • Export: CSV, PDF, GeoJSON din ecranul Export
  • Ștergere individuală: apăsând ținut pe o înregistrare → Șterge
  • Ștergere totală: butonul 🗑 din colțul dreapta-sus al ecranului principal
  • Portabilitate: Backup → export fișier .db

8. Securitate

Datele rămân pe dispozitiv — nu există transmisie în rețea inițiată de aplicație, nu există risc de breșă la server extern. Securitatea fizică a dispozitivului este responsabilitatea utilizatorului.

9. Modificări ale politicii

Orice modificare a politicii de confidențialitate va fi publicată pe această pagină. Data ultimei actualizări este afișată în antet.

🇬🇧 English · Last updated: August 2026

1. Data controller

TreeMeasureAR is developed and published by Florin Nicola, contact: nicolaflorin00@icloud.com.

2. Data collected and purpose

The app collects and stores data exclusively on the user's device:

Data category Details Required?
Forestry measurements Diameter (D1, D2, Dm), height, volume, basal area, tree number, quality class, species, forest unit Yes — core functionality
Precise GPS location WGS84 coordinates attached to each measurement and GPS track points Optional — user grants permission
Approximate location Derived from same ACCESS_FINE_LOCATION permission Optional
Stump photos Photos saved locally with watermark (GPS coordinates + stump number) Optional — separate stump inventory feature
App settings Operator eye height, diameter correction factor, last used forest unit Yes — local preferences

3. Storage

  • All data is stored in the app's internal database (treemeasurear.db) on the user's device.
  • No server, no user account, no cloud sync.
  • Photos are saved in the device's internal storage.
  • Settings are stored in local SharedPreferences.

4. Sharing with third parties

  • No automatic data transmission to any server or third party.
  • File export (CSV, PDF, GeoJSON) is initiated exclusively by the user.
  • The in-app map fetches OpenStreetMap tiles via HTTP; no user identifier is sent.
  • No advertising, analytics (Firebase, Crashlytics), or third-party tracking SDKs.

5. Permissions

  • CAMERA — required for augmented reality and stump photography
  • ACCESS_FINE_LOCATION — optional; requested only for geotagging and GPS track
  • READ_EXTERNAL_STORAGE — requested only on Android < 13 for backup/restore

6. Data retention

Data is retained on the device until the user explicitly deletes it (in-app button) or uninstalls the app.

7. User rights

  • Access: all data visible in the app (History screen)
  • Export: CSV, PDF, GeoJSON from the Export screen
  • Individual deletion: long-press a record → Delete
  • Delete all: 🗑 button in the top-right corner of the main screen
  • Portability: Backup → export .db file

→ Detailed data deletion instructions

8. Security

Data remains on the device — no network transmission initiated by the app, no risk of external server breach. Physical device security is the user's responsibility.

9. Policy changes

Any changes to this privacy policy will be published on this page. The last update date is shown in the header.
